L’objectif principal du projet Inception est de créer une infrastructure complète et fonctionnelle de services, basée sur des conteneurs Docker.
Les 3 services requis dans la partie mandatory du sujet sont :
- une base de données MariaDB (pour stocker les données),
- un site WordPress (pour afficher du contenu),
- un serveur HTTP NGINX (pour accéder au site via une URL).
Le projet contiendra donc 3 conteneurs, chacun hébergeant un service distinct.
